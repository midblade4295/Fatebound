# Native fantasy art pass

These game assets were generated with the built-in image generation tool using the visual reference supplied for the Fatebound redesign. They are stored as WebP for Android size and loaded by `battlefield.gd` and `dice_strip.gd`.

| Asset | Prompt direction |
| --- | --- |
| `hero_stage.webp` | Remove the armored knight from the reference-guided hex-stone diorama, preserving its towers, trees, perspective, moss, warm sunlight, cool depth, and an empty center for the selected hero. No UI or text. |
| `battle_arena.webp` | Vertical isometric fantasy battlefield with blue and crimson stone keeps, a neutral ruined tower, deep mountain atmosphere, sun rays, and a spacious readable hex-stone floor. No characters, dice, or text. |
| `hero_knight.webp` | Extract the silver-armored red-caped Knight with sword from the diorama as a full-body transparent character. |
| `hero_rogue.webp` | Matching full-body premium 3D miniature Rogue in teal hood, dark leather, and light armor with dagger on transparent background. |
| `hero_barbarian.webp` | Matching full-body Barbarian with fur, worn metal, crimson cloth, and a battle axe on transparent background. |
| `hero_mage.webp` | Matching full-body Mage in violet-blue robes, leather and small armor, arcane staff and turquoise glow on transparent background. |
| `hero_ranger.webp` | Matching full-body forest Ranger in green and brown leather with hood, longbow and quiver on transparent background. |
| `gold_die.webp` | One blank-front faceted gilt polyhedral die with transparent background. The engine overlays the authoritative roll symbol and matching glow. |

Class illustrations represent visual archetypes. Equipped weapon names and combat calculations still come from the saved state; the five character illustrations are not distinct renders of all 45 class-and-weapon combinations.
