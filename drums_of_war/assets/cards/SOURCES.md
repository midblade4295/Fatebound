# Card illustration sources

The pictures in `src/` are the uncropped card illustrations for Drums of War. Every one was generated
with ElevenLabs (ElevenCreative image generation, flow "Drums of War card art") for this project; none
is taken from another game or from stock art, and none depicts a real person.

- Model: `gpt-image-2.5-sunburst` (GPT Image 2.5 Sunburst), aspect ratio 4:5, resolution 1K, quality high.
- Each prompt was run once and produced four variations at 832 x 1040; the variation listed below was
  picked by eye and saved downscaled to 819 x 1024 (long side 1024) as JPEG, otherwise unedited and
  uncropped. `tools/make_card_art.py` makes the 320 x 400 game pictures beside this file from them.
- Reference images were wired into each generation as character/style references: the approved model
  reference pictures (`assets/models/*/ref.png`) and the approved Union character lineup sheet, all of
  which were themselves generated with the same model for this project.
- `src/.gdignore` keeps Godot from importing these sources; in-game card textures are meant to be cropped from them.
